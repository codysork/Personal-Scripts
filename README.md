# Scripts (A Suite of User Scripts)

This repository contains a suite of user scripts that I have written for use of
managing an Arch Linux installation, including system maintenance and reminders.
It was written for my own personal use, but has been designed to be easily
adapted for anyone else to use. It includes a handy configuration file to
include variables for all of the scripts, as well as install and uninstall
scripts.

## Installation

sudo ./install.sh

## Uninstallation

sudo ./uninstall.sh
